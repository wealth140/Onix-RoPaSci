# Onix-RoPaSci

A responsive Rock Paper Scissors game you can play against the computer.

## Play

Open `index.html` in a browser and choose Rock, Paper, or Scissors. Your score is saved in the browser.

Keyboard shortcuts: `R` for Rock, `P` for Paper, `S` for Scissors, and `Backspace` to reset the score.

The site can be hosted as a static website using GitHub Pages from the repository's `main` branch.
